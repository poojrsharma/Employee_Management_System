# Employee Management System

A desktop-based **Employee Management System** developed using **C#, Windows Forms, ADO.NET, and SQL Server**.  
The application provides an easy and efficient way to manage employee records and perform basic CRUD operations.

---

## 📌 Project Overview

The Employee Management System is designed to simplify employee record management.

Users can add new employees, view employee records, update existing information, delete records, and search for specific employees.

This project demonstrates practical implementation of **C# programming, Windows Forms, ADO.NET database connectivity, SQL Server, CRUD operations, and input validation**.

---

## ✨ Features

- Add new employee records
- View all employee records
- Update employee information
- Delete employee records
- Search employee records
- Input validation
- Clear form functionality
- Employee status management
- Display employee records using DataGridView
- SQL Server database integration
- ADO.NET based database operations

## 🔄 CRUD Operations

The application supports the following database operations:

**Create** → Add new employee

**Read** → View employee records

**Update** → Modify employee information

**Delete** → Remove employee records

**Search** → Find employee records

---

## 🗄️ Database

The application uses **Microsoft SQL Server** for storing employee information.

Database connectivity and database operations are implemented using **ADO.NET and SQL queries**.

## ⚙️ How to Run the Project

1. Clone or download this repository.

2. Open the project in **Visual Studio**.

3. Create the required database and employee table in **SQL Server**.

4. Update the SQL Server connection string according to your system.

5. Build the project.

6. Run the application.
